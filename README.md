# Dice Game

Guess **Over** or **Under** a number (0–100), roll the dice, see the result and history.

---

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

---

## Stack

Next.js 16 (App Router), React 19, MUI 7, TypeScript, Zustand, NumberFlow.
